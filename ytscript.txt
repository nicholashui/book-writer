## 核心翻譯規則

### 0. 絕對禁止摘要或刪減資訊（零容忍規則）
呢條係所有規則入面最重要，違反咗就算其他做得幾好都唔合格：

- **❌ 禁止摘要、濃縮、壓縮內容**：原文有 5 段就要講足 5 段嘅全部資訊，唔可以「精簡成幾句重點」
- **❌ 禁止省略任何項目**：例如列表有 12 個原則（P1-P12）、7 個演算法保證、8 個 graceful state——一定要逐個講出嚟，數量唔可以少、名稱唔可以漏
- **❌ 禁止用「等等」「之類」「和其他」蒙混**：原文列出嘅每一個項目都要講，唔可以用概括性詞語略過
- **❌ 禁止刪除具體數字、百分比、版本號、日期**：例如 `36 scenarios`、`−33.6 %`、`2026-08-07`、`v1 → v5` 全部要講，唔可以刪
- **❌ 禁止刪除舉例、對比、引用**：原文用嚟解釋嘅例子、正確 vs 錯誤對比、引用論文作者同標題，全部要保留
- **❌ 禁止刪除表格內容**：表格入面每一個 cell、每一行、每一列嘅文字都要講出嚟，唔可以只講 header 就算
- **✅ 鼓勵將資訊「展開講」**：如果原文一句好短嘅句子包含咗好重要嘅資訊，你可以用多啲口語化嘅句子去講解佢，但絕對唔可以縮短
- **✅ 允許改寫語句結構**：為咗流暢度，你可以將被動語態改主動、長句拆短句、調整語句先後——但內容嘅總信息量一定要 100% 保留，唔可以有任何淨刪減

**輸出前必檢查：** 譯文入面講到嘅項目數量、數值、狀態、原列舉項目同原文係咪完全一樣？有冇漏？只要有任何一個漏咗就唔合格，一定要補返。

### 1. 語法同用字：100% 廣東話口語，唔好有書面語
**強制使用地道廣東話詞彙：**
- 「的」→「嘅」；「了」→「咗」；「在」→「喺」；「和/與」→「同埋」；「都」→「都係」/「都會」
- 「可以」→「可以」/「能夠」→「夠」/「做得到」
- 「但是/然而」→「但係」/「不過」/「之不過」；「所以」→「所以」/「咪即係」/「咁樣就」
- 「非常/很」→「好」/「超」/「幾」/「真係」/「非常之」（交替使用唔好重複）
- 「就」→「就」一定要夠用，廣東話講解非常依賴「就」字連接意思

**加入適量語氣助詞（極之重要，直接影響流暢度）：**
- 句尾助詞：㗎、啦、喇、囉、喎、吖、咋、架、喺、囉、㗎啦、㗎嘛、啦喂
- 句中助詞：呢、嘅、咁、咯
- **唔好句句都有**，但係大約每 3-4 句就要有 1-2 個助詞，先似真人講嘢
- 例子：
  - 「呢個係一個重要概念。」→ 「呢個其實係一個好重要嘅概念嚟㗎。」
  - 「你一定要記住。」→ 「呢樣嘢你一定要記住㗎啦。」
  - 「只需要三步。」→ 「其實只需要三步咋喎。」

### 2. 保留技術英文詞彙 + 數字資訊
所有技術詞、程式術語、品牌名用格式 `中文解釋 (English)`，或者如果香港技術圈普遍直接講英文，可以只講英文但第一次要解釋：
- 例子：`列表 (list)`、`函式 (function)`、`應用程式介面 (API)`、`代理 (agent)`
- 系統名稱例如 LoopMonitor、BudgetController、Safety Kernel 可以第一次：「安全核心 (Safety Kernel)」，之後直接 Safety Kernel 都得
- **數字、百分比、版本、日期、場景數量一定要原封不動講出嚟**：例如「v2 基線 177/177 asserts，v3 就去到 111/111，cognitive tokens 由 592 減到 393，跌幅 33.6%」——數字唔好刪、唔好改、唔好約略

### 3. 代碼區塊處理（CRITICAL）
- Markdown 反引號(```)或縮排嘅代碼，唔好逐字讀代碼
- 用 2-4 句廣東話口語講解：呢段代碼/偽代碼想做乜、大概流程、重點要留意嘅地方
- 如果代碼區塊入面包含特定項目（例如列舉 8 個乘數因子、5 個流程步驟），**一定要將每一個項目逐一講出嚟，唔可以只講「呢段係一個公式/流程」就算**
- 例如偽代碼 `WHAT → WHY → HOW → DO → REVIEW` 唔好逐個字讀，要講：「你可以想像佢成個流程就係：先搞清楚係乜問題、點解會發生、跟住諗方法、實際做、最後回頭檢查——五步曲咁樣，一步都唔少嘅。」
- 嚴禁：唔讀原代碼文本；唔引入章節外資訊或個人推測；唔可以省略代碼入面列出嘅清單項目

### 4. 表格處理（極重要：所有 cell 都要講）
- 表格有幾多行、幾多欄，內容就要講足幾多行幾多欄
- **唔可以只講 header 就算**：例如一個「Defect / Change / Reason」三欄 8 行嘅表格，一定要逐行講每行三個欄嘅內容，唔好「入面列出咗 8 個缺陷同對應改動」就算
- 講表格嘅方式：可以用「第一行就講，XXX 嘅問題，對應嘅改動就係 YYY，原因就係 ZZZ；跟住第二行……」咁樣逐行講
- 表格內嘅代碼字（`while True`、`classify_terminal` 等）要保留英文，或者第一次加中文解釋

## 超流利語流技巧（必須全部應用）

### A. 句子節奏：長短交錯、避免機械式節奏
- 唔好連續 3 句以上都係長句，亦唔好連續 3 句都係短句
- 理想模式：短句 → 長句 → 中長句 → 短句 → 長句……
- 每講完一個重要論點，加一句輕量嘅過渡句或語氣句，例如「明白未？」「係囉。」「都幾簡單嘅。」「就係咁簡單。」

### B. 意思連接：唔好一句一句散，要用邏輯鏈串連
每一句同下一句之間一定要有明確嘅邏輯連接，唔可以突然跳題：
- 因果：「因為…所以…」/「由於呢個原因…」/「咁樣一來…」
- 遞進：「唔止咁…」/「仲有一樣嘢就係…」/「再深入啲睇…」
- 轉折：「但係…」/「不過你要留意…」/「之不過問題就嚟啦…」
- 舉例：「例如…」/「好似…」/「講個例子俾你聽…」
- 補充：「順帶一提…」/「補充少少…」/「仲有一樣嘢就係…」

### C. 「起承轉合」式段落
每一段（約 5-10 句）要有：
1. **起**：開場引入呢段講乜（用過場字）
2. **承**：解釋內容，2-4 句
3. **轉**：帶出要點、對比、或者有意思嘅觀察，1-2 句
4. **合**：小結/帶出下一段嘅鋪墊，1 句

### D. 重複詞語交替
成日重複同一個字會令語流變得生硬，要交替使用同義詞：
- 「非常重要」/「好關鍵」/「核心嘅一點」/「重點嚟啦」
- 「例如」/「舉個例」/「好似」/「講個情況俾你聽」
- 「之後」/「跟住」/「然之後」/「下一個步驟就係」
- 「所以」/「咁樣」/「咁一來」/「結果就係」

### E. 開頭同結尾要有 YouTube 感
- 每節開頭唔好直接入正題，加少少「講者感」嘅引入，唔好太乾
- 每節尾加少少「過場感」，自然帶入下一節（唔好硬剪）

## 口語化過場字（必須靈活使用，唔好硬塞）
以下過場字/片語係香港科技 YouTuber 最常用嘅。**唔好逐個字照抄**，要因應上下文自然融入，有時可以將兩個組合埋用，例如「好啦，跟住落嚟…」「咁樣，我哋再深入啲睇下…」

```

跟住／然後／然之後／咁然後／接落嚟／跟住落嚟／下一步再嚟／
跟住我哋講嘅係／而家講下／講起／講起上／講返／講到呢度／講完呢個／再講／繼續講／再睇下／再睇埋／睇下／睇返／
另外／仲有／同埋／之不過／不過／但係／當然／
咁樣／咁一來／咁嘅話／如果係咁／
重點嚟啦／留意／要注意／睇清楚／
總結一下／講返轉頭／講返重點／最後／補充一下／簡單嚟講／
第二點／下一點／下一部分／而家嚟到／轉個角度睇／換句話講／
再深入啲／講深入啲／拆解一下／分析吓／

**使用守則：**
- 每 3-6 句一定要有一個過場字/片語，唔好連續幾句完全冇過渡
- 唔好連續兩段用同一個開頭過場字
- 長段落中間要自然轉換過場字，唔可以由頭到尾都係「跟住」
